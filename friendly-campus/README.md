# 友善校園管理平台

台灣國小正向環境教育管理系統，使用 Google Apps Script + Google Sheets 建置。

## 功能

- 環教登記：記錄學生完成環境教育次數，完成後自動扣除剩餘次數
- 自願打掃表揚：老師或管理員登記自願服務，經管理員審核後列入表揚名單
- 區域通報：通報待清理區域，供老師帶隊打掃
- 意見回饋：老師提交意見，管理員回覆
- LINE 助手整合：管理員收到待審核通知，老師收到系統公告

## 技術架構

- **後端**：Google Apps Script（`Code.gs`）
- **前端**：Google Apps Script HTML Service（`index.html`）
- **LINE 綁定頁面**：LIFF（`liff.html`）
- **資料庫**：Google Sheets（5 個工作表）
- **樣式**：Tailwind CSS CDN

## Google Sheets 工作表結構

| 工作表 | 欄位 |
|--------|------|
| 學生清單 | id, 姓名, 班級, 年級, 需完成總次數, 已完成次數, 狀態, 通報老師, 備註, 更新時間 |
| 區域清單 | id, 通報老師, 區域, 詳細地點, 預估時間, 期望完成日, 狀態, 描述, 通報時間 |
| 打掃登記 | id, 區域id, 區域名稱, 類型, 帶隊老師, 學生id, 學生姓名, 班級, 登記時間, 完成狀態, 完成時間 |
| 意見回饋 | id, 提交者姓名, 類型, 標題, 內容, 提交時間, 處理狀態, 管理員回覆 |
| 系統設定 | 設定項目, 值, 說明 |

## 部署步驟

1. 建立新的 Google Apps Script 專案
2. 將 `Code.gs`、`index.html`、`liff.html` 貼入專案
3. 建立 Google Sheets，執行 `initSheets()` 初始化工作表結構
4. 在「系統設定」工作表填入以下 LINE 相關設定：
   - `line_channel_access_token`
   - `line_bot_basic_id`
   - `web_app_url`
   - `line_liff_id`
5. 部署為 Web App：執行身分「存取網頁應用程式的使用者」

## 角色權限

| 角色 | 功能 |
|------|------|
| 所有老師 | 全校統計、通報區域、環教登記、自願登記、表揚名單、意見回饋 |
| 班級老師 | 以上 + 查看自己班學生姓名與進度 |
| 管理員 | 所有功能 + 學生管理 + 帳號管理 + 回饋管理 + LINE 廣播 |

## 注意事項

- 全校統計頁面採去識別化設計，僅顯示數字，不顯示學生姓名
- 自願打掃需經管理員確認才列入公開表揚名單
- LINE 助手綁定透過 LIFF 自動對應角色，無需在 LINE 內手動選擇
