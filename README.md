# 我的校園助手

個人教學工具包，整合各項學校行政功能，透過 LINE 讓老師方便使用。換學校也能帶著走。

## 模組

| 模組 | 說明 | 狀態 |
|------|------|------|
| [friendly-campus](./friendly-campus/) | 友善校園環境教育管理 | ✅ 上線中 |

## 技術架構

- **後端**：Google Apps Script
- **資料庫**：Google Sheets
- **前端**：Tailwind CSS + 純 JavaScript
- **通知**：LINE Messaging API
